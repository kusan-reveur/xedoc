      About Xedoc

      Codex, in plain sight.

      Xedoc is a local observability dashboard for understanding what Codex is doing on your machine — in operational terms developers can inspect.

      Privacy

      What this UI displays

      • ✓
        Metadata, not conversations

        Thread IDs, timestamps, counts, model labels, and operational status.

      • ✓
        File facts, not file content

        Names, paths, sizes, kinds, and modification times within the scoped Codex home.

      • ✓
        Read-only requests

        Local inspection stays local; reset calendars use one fixed, cached public source and offer no write actions.
